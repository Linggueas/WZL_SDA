# WZL_SDA 串口调试助手

基于 Qt 6 开发的串口调试助手，支持串口收发、HEX/字符串模式、多文本循环发送、模板保存/载入以及接收数据的实时可视化。

## 功能特性

- **串口配置**：串口号（点击下拉自动刷新）、波特率、数据位、校验位、停止位、流控
- **数据发送**
  - 单次发送 / 定时发送（可自定义间隔）
  - HEX 发送 / 字符串发送（UTF-8）
  - 发送新行（追加 `\r\n`）
- **数据接收**
  - HEX 显示（带空格分隔） / 字符串显示
  - 接收时间戳显示
  - 接收区保存到文件、一键清空
  - 历史记录面板（可隐藏/显示）
- **多文本面板**
  - 7 组自定义文本，每组可选 HEX/字符串模式
  - 循环发送（可配置间隔 500~10000 ms）
  - 模板保存/载入（JSON 格式）、一键重置
- **数据可视化模式**
  - 实时折线图 / 柱状图 / 散点图
  - 十六进制数值显示（Y 轴 `0x%X` 格式）
  - 滚轮滚动查看历史数据、最大显示点数可调
  - 图表一键导出为 PNG 图片

## 环境要求

| 项目 | 版本 |
| --- | --- |
| 操作系统 | Windows |
| Qt | 6.9.1（MinGW 64-bit） |
| 编译器 | MinGW 64-bit（C++17） |
| 构建工具 | qmake |

依赖 Qt 模块：`core`、`gui`、`widgets`、`serialport`、`charts`

## 构建运行

1. 使用 Qt Creator 打开 `WZL_SDA.pro`
2. 选择 Desktop Qt 6.9.1 MinGW 64-bit 套件
3. 点击构建并运行

或使用命令行：

```bash
mkdir build && cd build
qmake ../WZL_SDA.pro
mingw32-make
```

## 使用说明

### 基本收发

1. 点击串口号下拉框选择要使用的串口（点击时会自动刷新可用端口）
2. 配置波特率、数据位、校验位、停止位、流控
3. 点击 **打开串口**，连接成功后相关配置项将被锁定
4. 在发送框输入内容，点击 **发送**；接收数据实时显示在接收区
5. 再次点击 **打开串口**（此时为"关闭串口"）关闭连接

### 定时发送

勾选 **定时发送** 并设置间隔（毫秒），程序将按间隔自动发送发送框内容；取消勾选恢复手动发送。

### 多文本循环发送

1. 在 7 组文本框中输入内容
2. 勾选某行前的复选框表示该行按 **HEX** 发送，否则按字符串发送
3. 勾选 **循环发送** 并设置间隔，程序将依次循环发送所有非空行
4. 点击 **保存/载入** 可将 7 组内容以 JSON 格式保存或导入，**重置** 清空全部内容

### 数据可视化

1. 点击 **可视化模式** 切换为图表界面
2. 点击 **开始** 开始采集串口接收数据（将数据按十六进制数值绘制），**停止** 暂停采集
3. 可在图表类型下拉框切换 折线图 / 柱状图 / 散点图
4. 鼠标滚轮可前后滚动查看历史数据窗口，通过数值框调整窗口内显示的点数
5. **保存** 将当前图表导出为 PNG，**清空** 重置图表与数据

> 注意：可视化模式按单个 HEX 值绘制曲线，建议发送单个字节的 HEX 数据，否则可能产生乱码显示。

## 说明

- 发送与接收均为 **UTF-8 编码**
- 串口操作在独立线程中执行（`QThread` + 信号槽跨线程通信），避免阻塞 UI
